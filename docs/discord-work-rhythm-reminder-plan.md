# Discord 업무 리듬 알리미 기획서

## 1. 프로젝트 개요

### 프로젝트명
Discord 업무 리듬 알리미  
(초기명: Discord 쉬는시간 알리미)

### 한 줄 소개
평일 업무 시간에 맞춰 출근, 쉬는시간, 점심, 스크럼, 퇴근 알림을 Discord 채널로 자동 전송하는 서버리스 기반 업무 루틴 자동화 도구.

### 개발 배경
인턴 근무 중 장시간 집중하다 보면 쉬는시간을 놓치거나, 점심 종료 및 스크럼 시간을 깜빡하기 쉬웠다. 기존 ChatGPT 알림은 개인 알림에는 적합했지만 팀 Discord 채널에서 함께 확인하기 어렵고, 컴퓨터를 켜두어야 하는 로컬 실행 방식도 장기 운영에 불편했다.

이에 따라 다음 조건을 충족하는 자동화 도구를 기획했다.

- 평일의 정해진 시간에 Discord 메시지 자동 전송
- 컴퓨터가 꺼져 있어도 계속 작동
- Discord 서버 또는 채널을 여러 개 등록 가능
- 시간, 요일, 기간, 메시지를 직접 수정 가능
- 특정 알림을 삭제하지 않고 개별 ON/OFF 가능
- 향후 전체 알림을 한 번에 켜고 끌 수 있도록 확장 가능

## 2. 목표

### 핵심 목표
1. 업무 중 휴식 시간을 놓치지 않도록 한다.
2. 출근, 점심, 스크럼, 퇴근 등 하루의 주요 전환 시점을 안내한다.
3. 설정 파일만 수정해 일정과 메시지를 관리할 수 있도록 한다.
4. 로컬 PC에 의존하지 않고 Cloudflare Workers에서 지속 실행한다.

### 비목표
- 복잡한 일정 관리 서비스 제작
- 사용자 계정 및 권한 관리
- 관리자 웹 화면 제공
- Notion 공지 내용을 직접 읽어오는 기능
- 휴일 API 연동
- Discord 명령어를 통한 실시간 설정 변경

## 3. 사용자 및 사용 시나리오

### 주요 사용자
- 원격 인턴 및 팀 프로젝트 참여자
- Discord를 업무 채널로 사용하는 소규모 팀
- 정해진 업무 리듬과 반복 알림이 필요한 개인

### 대표 시나리오
1. 오전 9시에 출근 알림과 스크럼·공지 링크를 확인한다.
2. 매시 48분에 쉬는시간 알림을 받아 스트레칭과 수분 섭취를 한다.
3. 오전 11시 48분에 점심시간 알림을 받는다.
4. 오후 12시 50분에 점심 종료 10분 전 안내를 받는다.
5. 스크럼 시간에 Notion 링크를 열어 진행 상황을 정리한다.
6. 오후 6시에 퇴근 알림을 받는다.
7. 인턴 기간 종료 후 날짜 조건에 의해 알림이 자동 중단된다.

## 4. 기능 명세

### 4.1 예약 알림
각 알림은 아래 속성을 가진다.

```js
{
  name: "알림 이름",
  enabled: true,
  startDate: "2026-07-06",
  endDate: "2026-07-31",
  days: ["Mon", "Tue", "Wed", "Thu", "Fri"],
  time: "09:48",
  message: "Discord로 전송할 메시지",
}
```

### 4.2 개별 ON/OFF
각 일정의 `enabled` 값을 수정해 삭제 없이 켜고 끌 수 있다.

```js
enabled: true  // 실행
enabled: false // 중단
```

### 4.3 전체 알림 일괄 ON/OFF
`schedule.js`의 전역 설정으로 모든 알림을 한 번에 제어한다.

```js
export const GLOBAL_SETTINGS = {
  enabled: true,
};
```

Worker는 일정 조회 전에 전역 설정을 먼저 확인하고, `false`이면 개별 `enabled` 값과 무관하게 전송하지 않는다.

```js
if (!GLOBAL_SETTINGS.enabled) {
  return null;
}
```

### 4.4 기간 제한
`startDate`, `endDate`를 통해 특정 기간에만 알림이 동작한다.

```js
startDate: "2026-07-06",
endDate: "2026-07-31",
```

종료일이 지나면 Worker는 계속 실행되지만 메시지는 전송하지 않는다.

### 4.5 요일 및 시간 설정
요일은 영문 약어 배열로 설정한다.

```js
days: ["Mon", "Tue", "Wed", "Thu", "Fri"],
time: "16:48",
```

시간은 한국 시간 기준 24시간제 `HH:MM` 형식을 사용한다.

### 4.6 여러 Discord 채널 지원
Cloudflare Secret `DISCORD_WEBHOOK_URLS`에 여러 웹훅 URL을 JSON 배열로 등록한다.

```json
[
  "개인 서버 웹훅 URL",
  "팀 서버 웹훅 URL"
]
```

하나의 알림을 등록된 모든 Discord 채널로 동시에 전송한다.

### 4.7 테스트 엔드포인트
배포된 Worker 주소 뒤에 `/test`를 붙이면 등록된 모든 웹훅으로 테스트 메시지를 전송한다.

```text
https://<worker-address>.workers.dev/test
```

## 6. 시스템 구조

```text
Cloudflare Cron Trigger
        │
        │ 매분 실행
        ▼
Cloudflare Worker
        │
        ├─ 전역 설정(GLOBAL_SETTINGS) 확인
        ├─ 현재 한국 시간 확인
        ├─ schedule.js 일정 조회
        ├─ enabled 및 기간 확인
        └─ 일치하는 일정이 있으면 전송
        ▼
Discord Webhook
        │
        ├─ 개인 Discord 채널
        └─ 팀 Discord 채널
```

### 주요 구성 요소
- **Cloudflare Workers**: 서버리스 실행 환경
- **Cron Trigger**: 매분 Worker 호출
- **JavaScript**: 일정 판별 및 메시지 전송
- **Discord Webhook**: Discord 채널 메시지 전송
- **Cloudflare Secret**: 웹훅 URL 비공개 저장
- **schedule.js**: 시간, 요일, 기간, 메시지 관리

## 7. 기술 선택 이유

### Cloudflare Workers
- 로컬 PC를 켜둘 필요가 없음
- 무료 범위 내에서 운영 가능
- Cron Trigger 지원
- 배포 및 재배포가 간단함
- 동일 Worker 이름으로 덮어쓰기 배포 가능

### Discord Webhook
- 별도의 Discord Bot 계정이 필요 없음
- 구현과 운영이 단순함
- 지정한 채널로 메시지를 바로 보낼 수 있음
- 여러 웹훅을 배열로 관리 가능

### 설정 파일 분리
실행 로직과 일정을 분리해 시간표 변경 시 핵심 코드를 수정하지 않도록 했다.

## 8. 배포 및 운영

### 최초 배포

```powershell
npm install
npx wrangler login
npx wrangler secret put DISCORD_WEBHOOK_URLS
npm run deploy
```

### 설정 변경 후 재배포

```powershell
npm run deploy
```

기존 Worker를 삭제할 필요 없이 같은 주소에 새 코드가 반영된다.

### 웹훅 변경

```powershell
npx wrangler secret put DISCORD_WEBHOOK_URLS
```

새 값을 입력하면 기존 Secret이 교체된다.

## 9. 향후 개선 계획

### 9.1 알림 그룹별 ON/OFF
출근, 휴식, 식사, 회의, 퇴근 그룹을 나눠 선택적으로 제어한다.

```js
groups: {
  work: true,
  break: true,
  meal: true,
  meeting: true,
}
```

### 9.2 채널별 선택 전송
현재는 모든 웹훅으로 같은 메시지를 보낸다. 향후 알림마다 전송 대상을 지정할 수 있도록 확장한다.

```js
targets: ["personal", "team"]
```

### 9.3 웹 기반 관리 화면
설정 파일을 직접 수정하지 않고 브라우저에서 시간, 요일, 기간, ON/OFF를 관리한다.

### 9.4 공휴일 제외
대한민국 공휴일 데이터와 연동해 평일이어도 공휴일이면 알림을 보내지 않는다.

### 9.5 Notion 연동
아침 알림에서 링크만 제공하는 대신, Notion API를 통해 당일 공지 내용을 요약해 Discord에 표시한다.

### 9.6 실행 이력 및 오류 알림
전송 성공·실패 이력을 저장하고, 웹훅 오류 발생 시 관리자 채널에 알린다.

## 10. 프로젝트에서 담당한 역할

- 인턴 근무 중 반복적으로 발생한 불편 정의
- 필요한 알림 종류와 시간표 설계
- 개인 및 팀 Discord 동시 전송 요구사항 정의
- 로컬 실행 방식과 서버리스 방식 비교
- Cloudflare Workers 배포 및 계정 연결
- Discord Webhook 생성 및 Secret 등록
- 시간·요일·기간·메시지 설정
- 테스트 메시지 검증
- 알림 문구 및 사용 흐름 개선
- 개별 ON/OFF 및 기간 제한 기능 요구사항 정의
- 향후 전체 ON/OFF, 채널별 전송, Notion 연동 방향 기획

코드 작성 과정에서는 생성형 AI의 도움을 적극적으로 활용했다. 다만 문제 정의, 요구사항 결정, 기능 우선순위, 설정, 배포, 테스트, 운영 방식 선택은 직접 수행했다.

## 11. 회고

처음에는 단순히 매시 48분에 쉬는시간을 알려주는 개인 알림으로 시작했다. 하지만 실제 사용 흐름을 점검하면서 점심, 업무 재개, 스크럼, 출근, 퇴근 등 하루의 전환 시점을 함께 관리하는 도구로 확장되었다.

로컬 Python 프로그램은 실행 창을 계속 유지해야 했고 Windows 배치 파일 인코딩 문제도 발생했다. 이를 계기로 실행 환경을 Cloudflare Workers로 전환했고, 컴퓨터 상태와 무관하게 작동하는 구조를 만들었다.

또한 시간과 메시지를 코드에 직접 고정하는 대신 설정 파일로 분리하고, 일정별 ON/OFF와 유효 기간을 추가해 운영 편의성을 높였다.

이 프로젝트는 대규모 서비스는 아니지만, 실제 불편을 발견하고 자동화 가능한 문제로 정의한 뒤, 생성형 AI를 활용해 구현하고 직접 배포·검증한 실사용 중심의 미니 프로젝트라는 의미가 있다.
